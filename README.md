Ми створили тестовий лог-файл test_access.log, який імітує запити до веб-сервера.
У логах є різні шляхи (наприклад /admin, /home, /login), IP-адреси користувачів і коди відповідей сервера (200, 404, 500 тощо).

Наше завдання — знайти всі IP-адреси, які зверталися до /admin і отримали код відповіді ≥ 400 (тобто помилки доступу або серверу).

Для цього створено bash-скрипт filter_admin_ips.sh, який автоматично шукає такі рядки у логах.

Назва файлу: filter_admin_ips.sh

🔹 1. Перевірка, чи існує лог-файл

Скрипт спершу перевіряє, чи існує файл test_access.log.
Якщо його немає — виводить помилку.

if [ ! -f "test_access.log" ]; then
  echo "Файл test_access.log не знайдено!"
  exit 1
fi

🔹 2. Пошук рядків з /admin

Команда grep знаходить усі запити до /admin:

grep "/admin" test_access.log

🔹 3. Відбір тільки помилкових запитів

Далі використовується awk для фільтрації рядків, у яких код відповіді ≥ 400:

awk '{ if ($NF >= 400) print $(NF-2), $NF }'


Тут:

$NF — останнє поле (код відповіді, наприклад 404)

$(NF-2) — IP-адреса (третє поле з кінця)

🔹 4. Збереження результату

Результат зберігається у новий файл bad_admin_ips.txt:

grep "/admin" test_access.log | awk '{ if ($NF >= 400) print $(NF-2), $NF }' > bad_admin_ips.txt

🔹 5. Виведення повідомлення

Скрипт повідомляє користувача про завершення роботи:

echo "✅ Результати збережено у bad_admin_ips.txt"

💻 Повний код скрипта
#!/bin/bash

# Скрипт для пошуку IP-адрес, які отримали помилки при зверненні до /admin

LOG_FILE="test_access.log"
OUTPUT_FILE="bad_admin_ips.txt"

if [ ! -f "$LOG_FILE" ]; then
  echo "❌ Файл $LOG_FILE не знайдено!"
  exit 1
fi

echo "🔍 Пошук невдалих запитів до /admin у файлі $LOG_FILE..."

grep "/admin" "$LOG_FILE" | awk '{ if ($NF >= 400) print $(NF-2), $NF }' | sort | uniq > "$OUTPUT_FILE"

echo "✅ Результати збережено у $OUTPUT_FILE"



🧾 Використані команди
grep	пошук рядків, що містять /admin
awk	вибір потрібних полів і перевірка кодів відповіді
sort, uniq	сортування та видалення повторів
echo	вивід інформаційних повідомлень
